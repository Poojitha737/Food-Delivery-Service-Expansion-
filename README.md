# MERN Project

Source-code organization extracted from the supplied MERN case-study report.

**Important:** the report title describes a healthcare appointment scheduling system, but the implementation/source-code section describes a food-delivery application (`foodapp`, restaurants, menus and carts). This repository preserves that source rather than silently changing its domain.

The report's sample authentication stores passwords in plain text/localStorage and returns a dummy token. Do not use it for a real production application and do not commit real credentials.

MongoDB is shown in the report as `mongodb://127.0.0.1:27017/foodapp`.
